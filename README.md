### About

- M.Tech student in **Data Science and Analytics** at MIT World Peace University (2025 - 2027); B.E. in Computer Science and Engineering.
- Previously worked as a **full-stack developer**; now combining that with data science, ML and LLM tooling.
- Currently building **FloatChat with X-RAG** - an explainable, evidence-linked forecasting and conversational system for Argo ocean data, aimed at journal publication.
- Outside of code, I write and publish **PC gaming guides for Discord** - game fixes, troubleshooting and co-op setup walkthroughs, formatted in Discord markdown so they are easy to follow and copy.
- Looking for **Software Developer, Full-Stack or Data Science / Analyst** roles.
